# Режим `--psy`: психоакустическая модель энкодера

Дополнительный режим работы энкодера: перцептивное распределение ошибки
квантования внутри **фиксированного** битового бюджета кадра. Битстрим,
контейнер и декодер не меняются — это чисто энкодерная надстройка, выходной
`.vqf` декодируется тем же FFmpeg/декодером.

Источники подхода (21 век):

- Herre, Dick — *Psychoacoustic Models for Perceptual Audio Coding —
  A Tutorial Review* (Applied Sciences, 2019): noise allocation / threshold
  adaptation для CBR — порог подгоняется под бюджет масштабным множителем
  вместо water-filling; FastEnc-принцип «психоакустика в MDCT-домене,
  консервативные константы».
- Zhen, Lee, Sung, Beack, Kim — *Psychoacoustic Calibration of Loss
  Functions for Efficient End-to-End Neural Audio Coding* (IEEE SPL, 2020):
  вес ошибки = функция отношения PSD к порогу маскировки (NMR-домен).
- Kandadai, Creusere — *Perceptually-Weighted Audio Coding that Scales to
  Extremely Low Bitrates* (DCC, 2008): перцептивное взвешивание поверх
  MPEG-4 TwinVQ.
- Valin et al. — CELT/Opus (ICASSP 2010, RFC 6716): статическая
  префиттированная аллокация + минимальные динамические ручки как
  индустриальный паттерн CBR.

## 1. Почему CBR — не ограничение, а друг

TwinVQ-кадр жёстко фиксирован (`frame_bit_len = bitrate·size/sample_rate`,
бюджет полей — §7 ARCHITECTURE). Из этого следуют два факта:

1. **Число бит не является переменной оптимизации.** Психоакустика не
   «сэкономляет» биты, а переставляет ошибку: где шум квантования неслышим,
   там ошибаться можно, где слышим — нельзя.
2. **PPC/wtype-гейты по «слышимости» бессмысленны**: биты PPC в LONG-кадре
   потрачены всегда (поля пишутся независимо), SHORT-скобки управляют
   временны́м разрешением, а не битами. Поэтому режим `--psy` НЕ трогает
   гейты PPC и грамматику wtype — только метрики ошибки.

«Фиттинг среднего значения» (идея из постановки задачи) реализован дважды:

- **офлайн**: константы модели (наклоны spreading, TMN/NMT, post-masking,
  β) калибруются по корпусу средним перцептивным качеством — процедура
  в §5;
- **в потоке**: адаптивные части модели (тональность, temporalmasking)
  считаются покадрово, но не меняют бюджет — только форму весов.

## 2. Модель маскировки (`src/psycho.rs`)

Порог маскировки считается на **мишени MDCT** `X` (амплитуды в масштабе
`c = 2^16/√(norm·b)`), поканально, на каждый подкадр (блок `b` бинов).

### 2.1 Полосы

Психоакустические полосы — шкала Цвиккера, по 1 барку, слитые до ≥1 бина:

```
bark(f) = 13·atan(0.00076·f) + 3.5·atan((f/7500)²)
```

44.1 кГц/LONG — ~25 полос; SHORT (b=128) — полосы грубее автоматически.
Ширина бина = sr/(2b).

### 2.2 Спектр, spreading, тональность

```
e_p  = (1/n_p)·Σ_{i∈p} X_i²                    — энергия на бин
s_p  = Σ_q e_q · 10^{−slope(Δ)/10},  Δ = z_p − z_q   (барки)
     slope(Δ>0) = slope_up  (маскировка вверх — пологая)
     slope(Δ<0) = slope_down (вниз — крутая)
α    = min(−10·log10(SFM)/60, 1)               — тональность (ISO Model 1)
     SFM = gm(e)/am(e) по полосам подкадра
OBC  = α·TMN + (1−α)·NMT                       — маскирующий офсет
t_p  = s_p · 10^{−OBC/10}                      — порог (энергия/бин)
```

Дефолты (консервативные, литературные): `slope_up=15`, `slope_down=27`
дБ/барк; `TMN=24` дБ (тон маскирует шум плохо), `NMT=4` дБ (шум маскирует
тон хорошо). Белый шум → α=0 → широкий порог; синус → α=1 → узкий,
глубокий.

### 2.3 ATH и SPL-калибровка

Абсолютный порог слышимости в единицах MDCT-мишени. Опорная точка:
полномасштабная синусоида (A=32767), выровненная с базисом MDCT, даёт пик
`fs_ref = A·(2¹⁷/π)·√(b/norm)` (выверено численно для b ∈ {128, 512, 2048};
косинус в центре бина без фазового выравнивания — в √2 меньше;
юнит-тест `fullscale_sine_peak`). Ей сопоставляется 96 дБ SPL:

```
ath_p = fs_ref · 10^{(ATH_dB(f_p) − 96)/10},  f_p — центр полосы
ATH_dB(f_кГц) = 3.64·f^−0.8 − 6.5·e^{−0.6(f−3.3)²} + 10⁻³·f⁴
t_p  = max(t_p, (ath_p·10^{ath_offset/10})²)   — ath_offset ≤ 0 (запас)
```

### 2.4 Временнáя маскировка (post-masking)

Каноническая сетка слотов по ½ барка (общая для всех ftype — частота одна).
Состояние на поток — по каналам. После кадра в слоты пишется максимум
порога по подкадрам; на следующем кадре:

```
t_p = max(t_p, t_prev_p · 10^{−post_mask_db/10})
```

т.е. порог спадает не быстрее `post_mask_db` (10 дБ по умолчанию) на кадр
(46 мс) — маскировка «держится» после громкого кадра.

### 2.5. Pre-masking (lookahead, v2)

Прямая маскировка слабее и короче post: базовое ослабление на dt=0
`pre_mask_db_base` (6 дБ), спад `pre_mask_db_per_ms` (1 дБ/мс), окно
`pre_mask_ms` (20 мс). Порог подкадра j поднимается будущими подкадрами:

```
t_j ← max(t_j, t_{будущий} · 10^{−(6 + 1·dt_мс)/10}),   dt ≤ 20 мс
```

Источники будущего: подкадры своего кадра (SHORT @44.1 — 2.9 мс/подкадр,
до ~6 вперёд) + первые подкадры СЛЕДУЮЩЕГО кадра (lookahead: encode_stream
считает мишени батча на +1 кадр, Phase B передаёт `next` в encode_frame).
Длинные кадры (LONG, 46 мс/подкадр) pre-masking не затрагивает — окно
короче подкадра, автоматически. Pre-вклад НЕ пишется в post-состояние
(будущий кадр сам поднимет свой порог — иначе двойной учёт). Отображение
полос между ftype — через ту же слот-сетку ½ барка.

## 3. Интеграция в конвейер (encoder.rs)

Точки входа — две метрики ошибки:

1. **Main VQ** (§4.6 ENCODE_PIPELINE): вес бина
   ```
   было:  w = (env·st·g)²                    — MSE в домене выхода
   стало: w = (env·st·g)² · m^{−2β}          — NMR-домен, m — порог (амплитуда)
   ```
   β — степень перцептивности. Бины ниже порога получают меньший вес →
   VQ-поиск (`search_w`) перестаёт тратить бюджет ошибки на неслышимые
   области; `search_w` нормирует веса и выбрасывает бины с w < 10⁻⁴·wmax.

2. **Bark-огибающая** (`quant_bark`): ошибка st в полосе взвешивается
   слышимостью полосы: `w_band = (env_rms/m_rms)^{2·β_bark}`;
   `β_bark = 0` — bark-слой как в базовом режиме.

**Ключевой эмпирический факт (калибровка §5): β ≈ 1 недопустим.** Порог
маскировки варьируется на 60+ дБ по спектру → веса 1/m² — на 120+ дБ.
Кодбуки VQ фиксированы, бюджет ошибки жёсток (zero-sum): при таком
диапазоне поиск жертвует не только замаскированные, но и слышимые полосы
(«нормировка на самый громкий бин» уносит всё). Измерения: при β=1
доля слышимых бинов over-mask растёт 0.33% → 3.4%; коллапс начинается
с β ≈ 0.3. Рабочая зона β ∈ [0.07, 0.2] — дефолт v2 **0.10** (с адаптивным
κ, §7), β_bark **0.1**.

Порядок вычисления: маска считается по исходной мишени `X` (до деления на
env/вычитания PPC) в начале кадра (шаг 1.5, ДО LSP — LSP-веса тоже могут
использовать маску); commit слотов post-masking — внутри mask_frame.
PPC-приёмка (чистое изъятие ≥2% энергии) и грамматика wtype
не меняются (см. §1).

Числовая дисциплина: модель живёт только на стороне энкодера в f64,
в замкнутый синтез-контур (реплика декодера) не вмешивается — риск
расхождения с FFmpeg-арифметикой отсутствует по построению.

## 4. CLI

```
tequila encode in.wav out.vqf --psy                # включить модель
  [--psy-beta F]         веса VQ, степень (0.10)
  [--psy-bark-beta F]    веса bark-полос, степень (0.1; 0 = как база)
  [--psy-lsp-beta F]     веса LSP (0 = выкл; на корпусе вредят, см. §7)
  [--psy-no-gain-w]      выключить адаптивный κ (абляция)
  [--psy-pre-mask F]     окно pre-masking, мс (20; 0 = выкл)
  [--psy-slope-up F]     spreading вверх, дБ/барк (15)
  [--psy-slope-down F]   spreading вниз, дБ/барк (27)
  [--psy-tmn F]          тон-маскирует-шум, дБ (24)
  [--psy-nmt F]          шум-маскирует-тон, дБ (4)
  [--psy-ath-offset F]   смещение ATH, дБ (−2)
  [--psy-post-mask F]    спад post-masking, дБ/кадр (10)
```

Без `--psy` кодирование бит-в-байт совпадает с обычным режимом (регрессионный
тест `psy_disabled_matches_default`).

## 5. Калибровка и валидация («фиттинг средним») — измерено

`python/analysis/psy_eval.py`: синтетический корпус (тон/мультитон/шум/
свип/клики/AM/FM/тон+шум/тон-тишина-тон; моно + стерео, 44.1 кГц, 13
конфигураций), кодирование базой и `--psy`, декод, метрики:

- **seg-SNR** по кадрам 2048 — raw-качество;
- **over-mask%** — доля бинов PSD, где шум квантования выше порога
  маскировки (маска пересчитана независимо в PSD-домене FFT по формулам §2);
- **NMR** — средний NMR (дБ) над порогом по этим бинам;
- **PEAQ ODG** (внешняя валидация, v2) — EAQUAL v0.1.3alpha
  (PEAQ-Basic, zplane.development; сборка `third_party/eaqual/BUILD.md`,
  патчи под современный gcc/libsndfile включены). 0 = без искажений,
  −4 = очень плохо. Внешняя по отношению к модели энкодера — та самая
  «независимая проверка», которой не хватало само-согласованному прокси.

Итог v2 (β=0.10, β_bark=0.1, адаптивный κ, pre-mask 20 мс, LSP-веса выкл):

| Метрика (среднее, 13 сигналов) | база | `--psy` v2 |
|---|---|---|
| seg-SNR, дБ | 28.01 | **32.23** (+4.2) |
| over-mask, % бинов | 0.33 | **0.15** (×0.45) |
| NMR над порогом, дБ | 2.14 | **1.58** |
| PEAQ ODG | −3.34 | **−3.24** |

По сигналам: tone_noise ODG −3.36→−1.66 (+1.7!), белый шум over-mask
1.54→0.50% и ODG +0.67, свип SNR 34.6→46.0, FM 43.8→59.3, синус
48.5→59.9. PEAQ-Basic при ODG ≈ −3.9 насыщается — разности на сильно
деградированных сигналах (клики/тишина) малоинформативны; выводы
держатся на ненасыщенных строках и на over%/SNR.

Абляции v2 (средние): LSP-веса (β_lsp=1) — **вредят** (SNR 25.1,
over 0.90%, ODG −3.52), выключены; адаптивный κ — главный вклад SNR
(27.4→30.6 без изменения over%); pre-masking на стационарном корпусе
нейтрален (LONG-кадры: окно 20 мс < подкадра 46 мс), включён для
транзиентов; β-сетка с адаптивным κ: 0.07→SNR 33.2/over 0.19,
**0.10→32.2/0.15/ODG −3.24 (оптимум)**, 0.15→30.6/0.15, 0.20→29.3/0.21.

История v1 (β=0.15 без адаптивного κ): SNR 27.4, over 0.16, ODG −3.21;
сетка β без κ: 0.1→0.17, 0.15→0.16, 0.2→0.19, 0.3→0.79, 0.5→2.44,
1.0→3.40 — коллапс полного деления виден явно.

Производительность: `--psy` ~+10% времени кодирования (взвешивание
прореживает активное множество VQ-поиска, но адаптивный κ добавляет
powf на бин).

## 6. Ограничения и направления

- Спектр полос — плотность энергии на бин: тональный пик размазывается по
  полосе (консервативно, недооценка маскировки тона до ~9 дБ на LONG).
- Стрео-маскировка (BMLD) не моделируется — каналы независимы.
- PEAQ-Basic (EAQUAL) сам упирается в насыщение на этих битрейтах;
  PEMO-Q/MultiNarrow или формальное прослушивание — следующий уровень
  внешней валидации.
- PPC-гейты и wtype-грамматика по-прежнему не психоакустические (§1 —
  в CBR это осмысленно); κ-адаптация (§7) закрывает «gain»-часть.

## 7. Адаптивный κ и LSP-веса (v2): механизм и эмпирика

**Адаптивный κ** («по перцептивной энтропии кадра»): σ-цель остатка
`κ·σ(книг)` настраивалась статически; теперь `g_des` считается по
перцептивно-взвешенному RMS остатка подкадра:

```
a(бин) = (env·st / m)^{2β}          — слышимость бина (g-независимая)
g_des  = sqrt(Σ a·v² / Σ a) / σ_target,   v = W/(st)
```

Механизм: bark-слой при β_bark>0 кодирует замаскированные полосы грубо →
их |v| «горбится» над σ(книг); невзвешенный RMS уводит gain вверх,
слышимые бины проваливаются НИЖЕ сладкой зоны кодбуков (α падает).
Взвешенный RMS выравнивает по слышимой части — эффективный κ
адаптируется к перцептуальной энтропии кадра автоматически. Измерено:
+3.2 дБ seg-SNR при том же over-mask, чисто выигрышная абляция.

**LSP-веса** (w_k = (|X|/m у частоты k-го LSP)^{2β_lsp} в критерии
split-VQ): реализованы, но на корпусе **вредят** (over% ×5.6, SNR −2.3 дБ,
ODG −0.31). Гипотеза: LSP-слой — грубая огибающая (23 бита), её ошибка
глобальна; перцептивное перераспределение точности внутри 20 коэффициентов
портит форму там, где маска «не видит» структуру (интерполяционные
quirk'и eval_lpcenv_or_interp усиливают локальные ошибки). Оставлены
флагом `--psy-lsp-beta` для экспериментов, дефолт 0.
